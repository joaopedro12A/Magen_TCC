Trabalho de Conclusão de Curso (TCC) do Campus UNASP São Paulo. O MAGEN usa sensores IoT para detectar e acompanhar fissuras em estruturas de concreto em tempo real, complementando (não substituindo) as inspeções visuais tradicionais.

## Hardware

| Componente | Função |
| --- | --- |
| ESP32 | Microcontrolador / coleta de dados |
| MPU6050 | Sensor de vibração/movimento |
| Arduino Uno | Placa de prototipagem |
